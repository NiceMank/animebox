PROMPT 12 — PARAMÈTRES, STOCKAGE, PRÉFÉRENCES ET FINALISATION UTILISATEUR

CONTEXTE
==================================================

Tu continues le développement de l'application mobile « AnimeBox ».

Les PROMPTS 1 à 11 ont déjà été exécutés.

NE RECOMMENCE PAS LE PROJET.

NE REFAIS PAS les écrans déjà conçus.

NE CHANGE PAS l'identité visuelle actuelle.

Cette étape est consacrée à la finalisation de l'expérience utilisateur et à la gestion des paramètres de l'application.

AnimeBox est une application Flutter Android fonctionnant principalement localement.

==================================================
OBJECTIF
==================================================

Créer une section Paramètres complète permettant à l'utilisateur de contrôler :

- son compte Telegram ;
- ses préférences ;
- les notifications ;
- la synchronisation ;
- les téléchargements ;
- la qualité préférée ;
- la langue ;
- l'apparence ;
- le stockage ;
- les données locales ;
- la confidentialité ;
- les informations de l'application.

Toutes les préférences doivent être persistantes.

2. COMPTE TELEGRAM
==================================================

Afficher clairement l'état du compte.

Si connecté :

Telegram connecté

Nom du compte

[ Gérer le compte ]

Si déconnecté :

Telegram non connecté

[ Connecter Telegram ]

Le bouton doit utiliser le système Telegram réellement implémenté dans le Prompt 11.

==================================================
3. DÉCONNEXION
==================================================

Permettre :

[ Déconnecter Telegram ]

Afficher une confirmation avant déconnexion.

La déconnexion doit :

- terminer la session Telegram ;
- arrêter les synchronisations ;
- empêcher les nouvelles synchronisations automatiques.

IMPORTANT :

Ne pas supprimer automatiquement :

- les animés ;
- les épisodes ;
- les favoris ;
- l'historique ;
- les fichiers téléchargés.

==================================================
4. QUALITÉ VIDÉO PAR DÉFAUT
==================================================

Ajouter :

Qualité préférée

Options :

Auto
2160p
1440p
1080p
720p
480p
360p

Valeur par défaut :

Auto

Cette préférence doit être utilisée lorsque l'utilisateur ouvre un épisode possédant plusieurs qualités.

==================================================
5. LANGUE
==================================================

Préparer le système d'internationalisation.

Langue principale :

Français

Prévoir une structure permettant d'ajouter ultérieurement :

English

Español

Português

etc.

NE PAS traduire artificiellement avec une API externe.

Les chaînes doivent être centralisées dans le système de localisation Flutter.

==================================================
6. CHANGEMENT DE LANGUE
==================================================

Lorsque l'utilisateur change de langue :

l'interface doit utiliser immédiatement la nouvelle langue lorsque possible.

Conserver le choix après redémarrage.

NE PAS modifier :

- les titres des animés ;
- les noms des fichiers Telegram ;
- les noms des canaux.

Seule l'interface AnimeBox doit être traduite.

==================================================
7. THÈME
==================================================

Prévoir :

Sombre

Clair

Système

Cependant :

le design principal AnimeBox reste le thème sombre.

Le thème clair doit uniquement être implémenté s'il peut respecter correctement l'identité visuelle existante.

NE PAS créer un thème clair générique.

==================================================

==================================================

==================================================
9. SYNCHRONISATION AUTOMATIQUE
==================================================

Afficher :

Synchronisation automatique

ON/OFF

Si activée :

Fréquence

15 min
30 min
1 h
3 h
1 jour

Respecter les limitations Android.

NE PAS prétendre garantir une fréquence exacte lorsque Android retarde les tâches en arrière-plan.

==================================================
10. SYNCHRONISATION WIFI
==================================================

Ajouter éventuellement :

Synchroniser uniquement en Wi-Fi

ON/OFF

Lorsque activé :

les synchronisations automatiques doivent éviter les opérations réseau lorsque la connexion n'est pas adaptée, selon les possibilités du système Android.

IMPORTANT :

La synchronisation concerne les métadonnées/messages nécessaires.

Elle ne doit pas télécharger automatiquement les vidéos.

==================================================
11. TÉLÉCHARGEMENT AUTOMATIQUE
==================================================

Prévoir la structure du paramètre :

Téléchargement automatique

OFF par défaut.

Si cette fonctionnalité a déjà été implémentée dans les étapes précédentes :

connecter correctement le réglage au DownloadManager.

Sinon :

NE PAS inventer un système incomplet.

Afficher uniquement l'option si elle est réellement fonctionnelle.

==================================================
13. NETTOYAGE DU CACHE
==================================================

Ajouter :

[ Vider le cache ]

Afficher une confirmation.

La suppression du cache ne doit PAS supprimer :

- vidéos téléchargées ;
- favoris ;
- historique ;
- catalogue ;
- sources.

==================================================
14. SUPPRESSION DES TÉLÉCHARGEMENTS
==================================================

Ajouter :

[ Gérer les téléchargements ]

Permettre éventuellement :

- supprimer un fichier ;
- sélectionner plusieurs fichiers ;
- supprimer plusieurs fichiers ;
- supprimer tous les téléchargements.

Toujours demander confirmation avant une suppression massive.

==================================================
15. ESPACE INSUFFISANT
==================================================

Si l'espace disponible devient faible :

afficher un avertissement.

Exemple :

« Votre espace de stockage est presque plein. »

Action :

[ Gérer le stockage ]

Ne pas empêcher inutilement l'utilisation du catalogue.

==================================================
16. DONNÉES LOCALES
==================================================

Préparer une section :

Données locales

Afficher :

Catalogue
Favoris
Historique
Préférences

Permettre :

[ Effacer les données locales ]

Cette action doit être clairement présentée comme destructive.

==================================================
17. CONFIRMATION DE SUPPRESSION
==================================================

Avant toute suppression importante :

afficher une confirmation explicite.

Exemple :

« Cette action supprimera vos données locales AnimeBox. Les vidéos téléchargées seront également supprimées. »

Ne jamais supprimer silencieusement des données importantes.

==================================================
18. RÉINITIALISATION
==================================================

Ajouter éventuellement :

Réinitialiser AnimeBox

Cette action doit :

- supprimer les données locales ;
- supprimer les préférences ;
- supprimer les sources ;
- supprimer l'historique ;
- supprimer les favoris ;
- supprimer les téléchargements ;
- déconnecter Telegram.

Afficher plusieurs avertissements avant exécution.

==================================================
19. CONFIDENTIALITÉ
==================================================

Créer une section expliquant simplement :

« Vos données restent sur votre appareil lorsque cela est possible. AnimeBox ne transfère pas vos vidéos vers un serveur intermédiaire. »

NE PAS promettre une confidentialité absolue si une bibliothèque externe ou un service nécessaire au fonctionnement transmet certaines données.

Rester factuel.

==================================================
20. DONNÉES TELEGRAM
==================================================

Ne jamais envoyer vers un serveur AnimeBox :

- session Telegram ;
- code de connexion ;
- mot de passe 2FA ;
- vidéos ;
- messages Telegram.

Utiliser uniquement les composants nécessaires au fonctionnement réel de Telegram.

==================================================
27. PAS DE FAUSSES OPTIONS
==================================================

RÈGLE ABSOLUE.

NE PAS afficher un paramètre simplement pour donner l'impression que l'application possède une fonctionnalité.

Si une option n'est pas réellement connectée à un service :

ne pas l'ajouter.

Chaque switch, bouton ou sélecteur doit produire un effet réel.

==================================================
28. ERREURS
==================================================

Gérer proprement :

- impossibilité d'enregistrer une préférence ;
- stockage inaccessible ;
- erreur de suppression ;
- erreur de déconnexion Telegram ;
- erreur de nettoyage ;
- erreur de récupération de l'espace disque.

Afficher un message compréhensible.

==================================================

==================================================

Respecter strictement le design AnimeBox existant.

NE PAS refaire les écrans.

NE PAS transformer Paramètres en interface Android générique.

Conserver :

- thème ;
- typographie ;
- espacements ;
- arrondis ;
- animations ;
- navigation ;
- identité violette ;
- hiérarchie visuelle.
